# 🌱 Agri-Solution - Smart Farming Assistance Platform

> A student-built platform empowering farmers and knowledge seekers with modern agricultural solutions.



## 📖 About The Project
Agri-Solution is a web platform developed by us to bridge the gap between traditional farming and modern technology. It provides farmers, students, and agriculture enthusiasts with easy access to crop information, weather updates, government schemes, crop information, and smart farming tools - all in one place.

This project was built with the vision of **"Technology for Every Farmer"**.

### 🎯 Problem We Solve
- Lack of centralized information for farmers
- Difficulty in accessing weather, market rates, and government schemes
- Limited knowledge about modern farming techniques and crop diseases
- Language and technical barriers for rural users

## ✨ Key Features

### For Farmers:
- 🌦️ **Weather Forecast** - 7-day weather updates for better planning
- 🌾 **Crop Guidance** - Crop selection, sowing time, fertilizer and irrigation tips
- 🐛 **Disease Detection** - Identify crop diseases with images & get remedies
- 💰 **Market Price (Mandi Bhav)** - Daily market rates of crops
- 🏛️ **Govt. Schemes** - Latest PM-Kisan, subsidies and loan information
- 📞 **Ask Expert** - Direct chat/call with agricultural experts

### For Knowledge Seekers / Students:
- 📚 **Knowledge Hub** - Articles, blogs, and videos on organic farming, hydroponics
- 🧪 **Agri Tools & Calculators** - Seed calculator, fertilizer dose calculator
- 🗺️ **Soil Health Info** - Soil types and suitable crops
- 👥 **Community Forum** - Q&A forum for farmers and students

## 🛠️ Tech Stack

**Frontend:** HTML5, CSS3, JavaScript / React.js
**Backend:** Node.js / Python (Django/Flask)
**Database:** MySQL / MongoDB / Firebase
**APIs:** OpenWeather API, Government Data API, Crop Disease ML Model
**Tools:** Git, GitHub, VS Code, Figma
